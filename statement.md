# Project Statement: Expense Tracker
---

## Problem Statement

A lot of people, particularly students, tend to spend small amounts of money on a daily basis without recording those expenses. Eventually, they are unable to recall their expenditures, the largest single expense, or the category into which the majority of their money goes.
However, spreadsheets or accounting software are often too much effort to work with for something so simple.

> Problem: Create/use a simple program in which a user can enter expenses with a name, amount, and category, and quickly view the total amount spent, the largest expenditure, and the costs in any specific category.
---

## Scope of the Project

### In Scope

- A console-based (CLI) program in Python 3
- Entering expenses with a name, amount, and category
- Viewing all expenses
- Calculating the total expenses
- Showing the expense with the highest amount
- View all expenses by a particular category (case-insensitive)
- Multiple numbered options in a repeating menu, with some error-checking on the input
- Modular code, using separate files for each component

### Out of Scope (for this project)

- Database and/or file storage, for persisting the data between program runs
- Graphical or web-based UI
- Edit or delete capability
- Date, budget, or charting features
- Multi-user or account system
---

## Target Users

| User | Benefits |
|------|----------|
| Students | Track their pocket money, without having to learn how to use a spreadsheet or accounting software |
| People new to budgeting | Learn and develop the habit of tracking their expenses |

| People who want a fast tally | Quickly see the total amount and major categories of their expenses |
| Python learners | See a real-life example of using modules, lists, dictionaries, and loops in Python |
---
## High-Level Features
| # | Feature | Description |
|---|---------|-------------|
| 1 | Add Expense | Name, amount, and category of an expense |
| 2 | View All Expenses | See the list of all expenses |
| 3 | View Total Expenses | View the total amount of all expenses combined |
| 4 | View Highest Expense | See the expense with the highest amount |
| 5 | View Expenses By Category | Specify a category and see all expenses in it |
| 6 | Exit | Quit the application |
